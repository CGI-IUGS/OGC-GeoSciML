# OGC 16-008 GeoSciML 4.1: published version

These are unmodified copies of GeoSciML 4.1 as published by OGC. They are the reference for checking the Metanorma conversion in `releases/4.1/`. That conversion has **not yet been verified** against this publication.

| File | Status | Source |
| --- | --- | --- |
| `16-008.html` (and its asset files) | **Normative** | https://docs.ogc.org/is/16-008/16-008.html |
| `errata.html` | Errata for 16-008 and 16-008r1 | https://docs.ogc.org/is/16-008/errata.html |
| `16-008.pdf` | Informative: Word export from February 2017. Its own title page says it is not the official standard. | [SOURCE URL] |

Retrieved 2026/11/17 with `wget -p` (links not rewritten). Checksums are in `SHA256SUMS`.

## Notes

- **16-008r1 changed the schemas, not the text.** The XML schemas were re-posted as version 4.1.1 in the existing `gsml/4.1/` folder (see https://schemas.opengis.net/gsml/ReadMe.txt). The document's links to `gsml/4.1` are therefore still correct, and this HTML is the current publication.
- **The PDF misprints the publication date** as 2016-01-31. The HTML gives 2017-01-31.
- **The HTML embeds its 109 figures as images.** Nearly all of its size is those images, and it includes OGC's analytics script.
